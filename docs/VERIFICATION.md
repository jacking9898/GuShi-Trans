# 首版验证记录

日期：2026-11-17。Node.js 24.16.0，Playwright 1.65.1，Chrome for Testing 159.0.8154.6；macOS arm64。

## 已通过

- `npm run check`：Manifest V3、入口文件、图标、HTML 本地引用、JavaScript 语法。
- `npm test`：21 项逻辑测试全部通过。包含基础地址拼接、Unicode 长度、输入校验、响应与流式 SSE 解析、错误脱敏、内容脚本的密钥访问限制、上下文默认关闭、收藏并发保存与去重、取消请求的来源隔离，以及设置读取阶段的立即取消。
- `npm run test:e2e`：独立临时 Chromium 用户配置中运行，完整扩展页面和后台代码参与测试。
  - 未配置时的引导，以及明确标记的内置示例。
  - 设置保存与 Chrome 权限 API 调用。
  - 真实 HTTP 请求到本地模拟 AI 接口，流式和普通 JSON 两种响应。
  - 收藏、搜索、生词笺 JSON 导出，且导出中没有密钥。
  - 401 错误的安全提示及恢复重试。
  - AI 返回 HTML 时仅展示文字，不创建标签或执行脚本。
  - 取消后重新查询，不被旧结果覆盖。
  - 在严格 CSP 网页中真实选择文字，打开闭合 Shadow DOM 浮窗并展示译注。
  - 点击字词继续查询，关闭面板，编辑区域不触发划词。
  - 阅读页和设置页在 320 / 768 / 1024 / 1440 像素宽度下没有水平溢出。
  - 全流程没有未捕获的页面异常。

## 验证边界

自动化无界面浏览器不能点击 Chrome 的原生可选权限授权弹窗，因此浏览器测试使用**临时 manifest** 预授予唯一的 localhost 模拟接口权限；扩展运行时代码逐字节复用源文件，发布 manifest 不包含该预授权。正常安装后的原生授权弹窗应由用户保存设置时确认。Node 逻辑测试另行覆盖了未授权时禁止请求的分支。

未使用真实用户密钥，也未调用真实 DeepSeek 或其他付费模型。真实服务可用性、生成内容的准确度、系统语音发声及多音字发音，需在用户本机配置后检查。没有进行 Chrome 应用商店发布。

可复现命令及依赖安装见项目 README。界面截图位于 `test-results/`，不包含真实密钥或私人页面。
